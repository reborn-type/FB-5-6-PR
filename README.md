# 1 Контрольная Фронтэнд и Бекэнд разработа

В рамках 1КР реализовано 5 практических заданий: 

- 1ПР: Реализован UI(User Interface) с помощью SASS и LESS
- 2ПР: Реализован базовый сервер на node.js, с эндпоинтами реализующие правила CRUD (Create, Read, Update, Delate)
- 3ПР: Работа с Postman для отправления запросов на сервер и получения результата
- 4ПР: Реализован полноценный сайт с фронтенд и бекэнд составляющей, которые разбиты по разным http портам, при помощи Express JS и ReactJS
- 5ПР: Реализована OpenAPI при помощи swagger, где документация находится по адресу http://localhos:3001/api-docs/

## Итоги первой контрольной работы
Итогом 1 КР стал сайт с полноценным функционалом добавления, удаления и редактированию приложений, с реализованной документацией, и UI.
